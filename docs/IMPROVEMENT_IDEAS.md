# Ideas de mejora y practica

- Cambiar puertos externos y comprobar que los internos no cambian.
- Agregar una tabla simple en PostgreSQL.
- Crear una migracion con una herramienta como Alembic.
- Agregar un nuevo endpoint de lectura.
- Provocar un error de credenciales y analizar logs.
- Apagar PostgreSQL y observar la respuesta de `/health`.
- Cambiar `LOG_LEVEL` entre `INFO` y `DEBUG`.
- Crear un backup con `make backup`.
- Restaurar un backup con `make restore BACKUP_FILE=...`.
- Agregar un segundo servicio auxiliar.
- Configurar HTTPS con un proxy reverso.
- Agregar autenticacion a la API.
- Agregar monitoreo.
- Implementar pipelines ETL.
- Conectar Power BI a PostgreSQL.
- Migrar componentes a Azure.
